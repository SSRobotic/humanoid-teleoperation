## 🚀 Start here

1. Choose an interface supported by the target robot and XR / tracking equipment.
2. Check calibration, motion retargeting and stream / coordinate conventions.
3. Use the project’s documented environment to inspect inputs and recorded demonstrations.

Read the [engineering guide](GUIDE.md) for a practical selection checklist. [resources.json](resources.json) contains the structured entries.
